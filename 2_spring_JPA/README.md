# Spring Data JPA + Hibernate

Now let's move to the next step: **Spring Data JPA + Hibernate**.

This is where you'll learn how to save your data to a **real database**, instead of keeping it only in memory (like we did with `ArrayList` in Spring MVC).

---

## 🎯 What's the Difference?

### Before (Spring MVC)

```java
private List<Book> books = new ArrayList<>(); // Lost when app restarts!
```

- Data is stored **in memory only**
- All data is **lost when the application restarts**
- Useful for learning basics, but **not for real applications**

### Now (Spring Data JPA + Hibernate)

```java
// Data saved to database - persists even after restart!
```

- Data is stored in a **database**
- Data **persists even after restarting** the application
- Uses **JPA (Java Persistence API)** with **Hibernate** as the ORM
